Common issues

The app will not open

After downloading from the internet, macOS may block the first launch. Open System Settings → Privacy & Security and allow SISR, or right-click the app and choose Open.

“Could not read directory” / empty after Open

Grant folder access when the Open panel appears. Re-open the sequence folder if a bookmark expired. The native app expects a folder that itself contains the numbered frames (not only a parent of many sequences).

Render fails or runs out of memory

Try a lower output size, keep auto bitrate, shorten the in/out range, or close other memory-heavy apps. Very long 4K sequences need more RAM during encode.

Date overlay is blank

Overlays use embedded capture dates when present. Files stripped of EXIF will not show a camera date.

Contact

Prefer public bug reports so others can benefit:

  • GitHub Issues — timelapsetech/SISR-MacOS

Include your macOS version, SISR version (from the About window or release tag), and what you expected versus what happened. Do not attach private photo libraries unless you intend to share them.
