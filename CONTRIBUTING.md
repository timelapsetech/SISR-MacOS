# Contributing to SISR for macOS

Thanks for helping improve SISR.

## We develop with GitHub

We use GitHub to host code, track issues and feature requests, and accept pull requests.

## GitHub Flow

1. Fork the repo and create your branch from `main`.
2. If you add behavior, add or update tests in `Packages/SISRKit`.
3. Update docs under `docs/` when user-facing behavior changes.
4. Ensure package tests pass: `make test`.
5. Open a pull request.

## License

## Report bugs

Use the [issue tracker](https://github.com/timelapsetech/SISR-MacOS/issues). Include macOS version, SISR version, steps to reproduce, and expected vs actual behavior.
